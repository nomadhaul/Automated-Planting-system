# ICS Environmental Control (Automated Water Plant)

## Overview
An automated environmental control system developed for ENSC 1411. This project integrates thermal telemetry and physical water-level sensors to manage and actuate hardware mechanisms remotely based on dynamic environmental conditions.

## Architecture & Capabilities
* **Sensor Integration:** Real-time data parsing from temperature and moisture sensors.
* **Actuator Logic:** Automated kinetic response (water deployment) triggered by threshold-based logic.
* **Remote Administration:** Designed to allow external monitoring and manual overrides of the physical plant hardware.

## Security Context
Demonstrates foundational Industrial Control Systems (ICS) principles: parsing physical environmental data and translating it into safe, bounded hardware actuation.
